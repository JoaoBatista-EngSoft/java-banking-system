# 🏦 Java Banking System

A simple banking system developed in Java to practice Object-Oriented Programming concepts and backend fundamentals.

The project simulates basic banking operations, allowing users to create accounts, perform deposits, withdrawals, transfers and check account information.

---

## 🚀 Features

- Create bank accounts
- Deposit money
- Withdraw money
- Transfer money between accounts
- Check account balance
- List all accounts

---

## 🛠️ Technologies

- Java 17+
- Object-Oriented Programming (OOP)
- Collections Framework
- Git and GitHub

## ▶️ How to Run

### Clone the repository

```bash
git clone https://github.com/JoaoBatista-EngSoft/java-banking-system.git
```

### Navigate to the project folder

```bash
cd java-banking-system
```

### Compile the project

```bash
javac src/*.java
```

### Run the application

```bash
java -cp src Main
```
